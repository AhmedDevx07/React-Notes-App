# 📝 React Sticky Notes App

A modern and responsive Sticky Notes application built with **React.js** that allows users to create, manage, and save notes efficiently. The application supports persistent storage using browser localStorage and includes a voice-to-text feature for hands-free note creation.

## 🚀 Live Demo

🔗 Live Preview: https://react-notes-app-wheat-two.vercel.app/

## 📂 GitHub Repository

🔗 Repository: https://github.com/AhmedDevx07/React-Notes-App

---

## ✨ Features

* Add new notes instantly
* Delete notes easily
* Persistent data storage using Local Storage
* Responsive Masonry Grid Layout
* Voice-to-Text functionality for note creation
* Smooth UI interactions with animations
* Mobile-friendly design

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/AhmedDevx07/React-Notes-App.git
```

Move into project directory:

```bash
cd React-Notes-App
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
